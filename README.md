# A Fork of Emacs Evil

This only works on Emacs 30.1 or later. The fork intended for personal use, and is not
maintained by the original Evil developers.

If you want the original Evil, please visit the [official Evil repository](https://github.com/emacs-evil/evil).

## Dependencies

- Evil requires Emacs 30.1 or later.

- [goto-chg.el](https://github.com/emacs-evil/goto-chg)
